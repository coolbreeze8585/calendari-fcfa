# Calendari auxiliar FCFA 🏈

**Temporada 2026–2027**

Calendari de consulta de les competicions de futbol americà i flag football organitzades per la Federació Catalana de Futbol Americà (FCFA).

## Sobre el projecte

Aquest projecte neix amb l'objectiu de facilitar la consulta de jornades, partits, seus, horaris i altres activitats relacionades amb les competicions de la FCFA.

Es tracta d'una eina auxiliar, gratuïta i accessible des de qualsevol dispositiu, especialment pensada per a jugadors, entrenadors, àrbitres, clubs i aficionats.

## Funcionalitats

L'aplicació està en desenvolupament. Les funcionalitats previstes són:

- Calendari visual de divendres a dilluns.
- Consulta de jornades i partits per competició.
- Informació sobre horaris i seus.
- Identificació de caps de setmana bloquejats, descansos i festius.
- Vista cronològica de les activitats.
- Filtres per competició.
- Accés des de mòbils, tauletes i ordinadors.
- Possibilitat d'instal·lar l'aplicació com a PWA.

## Estat del projecte

🚧 **En desenvolupament**

La primera versió de la web ja està publicada i connectada a una base de dades de calendari.

S'aniran incorporant progressivament les funcionalitats i la informació disponible.

## Avís important

**Aquest és un projecte independent, no oficial i sense vinculació institucional amb la Federació Catalana de Futbol Americà (FCFA).**

No ha estat desenvolupat, encarregat, supervisat ni validat per la federació.

La informació publicada té una finalitat exclusivament orientativa i pot contenir errors, omissions o dades provisionals.

Les dates, els horaris, les seus i la programació dels partits poden experimentar modificacions.

**En cas de discrepància, sempre prevaldran les comunicacions i la documentació oficial de la FCFA.**

## Accés a l'aplicació

La web es pot consultar gratuïtament a través de GitHub Pages.

## Tecnologia

- HTML, CSS i JavaScript.
- Google Sheets com a font de dades.
- Google Apps Script per a l'API de consulta.
- GitHub Pages per a l'allotjament públic.
